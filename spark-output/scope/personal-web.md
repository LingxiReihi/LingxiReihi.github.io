## 产品定位

单人维护的个人博客站：前台五栏目（落地主页 / 博客 / 模型[3D+渲染图+动画] / 杂谈 / 个人主页），后台支撑随时上传、修改、监控；视觉锁定 **B 靛蓝科技主题、强调色 #39C5BB**；部署后**须符合百度推送/收录规则**。

## 目标

**业务目标**
- 站点被百度正确收录与主动推送（⚠️ 新增硬目标）
- 作者脱离代码、经后台自主运营全部内容

**产品目标**
- 落地页 → 各栏目导流顺畅
- 3D/渲染/动画三类媒体高质量 Web 呈现
- 上传→发布→前台即时可见；看板回答「谁来了、看了什么」

## 目标用户

作者本人（唯一管理员）；中文技术/艺术访客（搜索与社交分享为主要来源）；潜在合作方/HR。

## 约束

Vue3 全家桶 + FastAPI + SQLite（已锁定）；主题 B + #39C5BB（显式）；百度合规 ⇒ HTML 服务端含正文 + HTTPS + 移动适配 + sitemap；单管理员；docs/ 三份文档需同步修订。

**不做**：评论系统（默认关）、多作者、付费、i18n。

## 设计 implications

1. Token 重构：深底 + #39C5BB 单强调色，逐屏对比度校验（AA ≥4.5:1）；玻璃拟态克制使用
2. **渲染架构被推翻重来**：SPA + 前端运行期 MD 渲染百度不可见 → vite-ssg 预渲染（推荐）或后端直出，详情页为必渲染路由
3. slug 语义化且发布后不可变；sitemap 含 lastmod；增量推送挂发布事件
4. 后台发布流增加「推送百度」状态反馈（失败可重试、不阻断发布）
5. 3D/动画对爬虫不透明 → 详情页服务端输出文字描述 + 渲染图 + 结构化参数，媒体做渐进增强
