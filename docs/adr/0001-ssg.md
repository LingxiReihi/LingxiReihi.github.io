# ADR-0001：vite-ssg 28.3 × Vite 8 (Rolldown) 预渲染实测结论

- **日期**：2026-09-22 ｜ **状态**：已采纳
- **验证方式**：最小双路由 spike（`/`、`/about`），`npx vite-ssg build` 全链路通过
- **结论**：
  1. vite-ssg@28.3.0 与 vite@8.3.0（Rolldown 内核）、vue@3.5.43、pinia 完全兼容，无需降级
  2. 产物为**平铺 HTML**（`dist/index.html`、`dist/about.html`），Caddy 静态服务需配置 `try_files {path}.html {path}/index.html {path} /index.html`（SPA fallback 兜底未预渲染路由）
  3. API 注意：v28 无 `useSSGContext` 导出；上下文经 ViteSSG 第三参 `({ isClient, initialState })` 注入
  4. 构建依赖后端在跑（拉 published 数据）→ 按规格实现 fail-fast：fetch 枚举路由失败即 build 报错，禁止静默空壳
- **降级预案**（未触发）：独立 Node 脚本调 `@vue/server-renderer renderToString` 生成各路由 HTML
